# pet-wb #3 宠物友好地图 — 测试说明

> **版本**：v1.0  
> **测试范围**：地图展示/地点筛选/详情/导航/搜索/收藏/打卡（纯地图模式，无 MBTI 标签社交）  
> **前置条件**：共享层 + #2 穿搭已通过验收

## 测试环境准备

- [ ] `cloudfunctions/mp-place` 已部署
- [ ] `mp_place` 表已插入至少 10 条测试地点数据（深圳/广州）
- [ ] 微信开发者工具已开启位置模拟
- [ ] Feature flag `module_mp_enabled` = 1

| # | 操作步骤 | 预期结果 | 状态 |
|---|---------|---------|------|
