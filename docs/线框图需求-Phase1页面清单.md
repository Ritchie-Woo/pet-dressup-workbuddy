# pet-wb Phase 1 低保真线框图需求描述

> **目标读者**：ui-designer  
> **用途**：基于此文档设计低保真线框图（信息架构 + 交互流程，非美工细节）  
> **范围**：Phase 1 全部 13 个页面（共享层 4 个 + #2穿搭 5 个 + #5团购 4 个）  
> **设计原则**：粒子性架构、移动端优先（小程序 375pt 视口）、底部 Tab-bar 导航

---

## 一、全局导航结构

### 1.1 底部 Tab-bar（4 个 Tab）

| Tab | 名称 | 对应模块 | 图标含义 |
|-----|------|---------|---------|
| 1 | 穿搭 | #2 桌宠穿搭 | 衣架/衣服 |
| 2 | 商城 | #5 团购 | 购物袋 |
| 3 | 地图 | #3 地图（Phase 1.5，先放占位） | 地图标记 |
| 4 | 我的 | 共享层（用户中心） | 人形轮廓 |

**Phase 1 实际可用 Tab**：穿搭、商城、我的（地图 Tab 显示但点击提示「即将上线」）

### 1.2 页面跳转关系

```
[穿搭 Tab] → 宠物选择页（如有多宠） → 穿搭主页
    ├─ 穿搭主页 → 换装编辑器
    ├─ 穿搭主页 → 穿搭方案列表
    ├─ 穿搭主页 → 分享卡片生成
    └─ 穿搭主页 → 服饰收藏（我的服饰）

[商城 Tab] → 团购商品列表
    ├─ 商品列表 → 商品详情
    │   └─ 商品详情 → 下单/支付页 → 支付成功
    └─ 商品详情 → 穿搭预览（联动 #2 的 2D 形象）

[我的 Tab] → 用户中心
    ├─ 用户中心 → 宠物档案管理（列表 + 新增/编辑）
    ├─ 用户中心 → 地址管理（列表 + 新增/编辑）
    ├─ 用户中心 → 订单管理（列表 + 详情）
    └─ 用户中心 → 设置/关于
```

## 五、关键交互流程

### 5.1 核心闭环：穿搭 → 购买 → 解锁

```
穿搭主页（看中服饰）
  → 点击「购买同款」
  → 商品详情页（查看规格 + 试穿预览）
  → 选择规格 + 确认地址
  → 微信支付
  → 支付成功（自动解锁服饰）
  → 返回穿搭主页（新服饰已出现在收藏）
```

### 5.2 分享裂变

```
穿搭主页 → 分享
  → Canvas 生成分享卡片（2D形象 + 穿搭名称 + 小程序码）
  → 保存图片 / 发送好友
  → 好友扫码进入 → 登录 → 创建宠物 → 触发穿搭引导
```

### 5.3 新人引导（3 步）

```
Step 1: 创建宠物档案
Step 2: 选择 2D 基础形象（8 种预设）
Step 3: 试穿免费服饰 → 分享穿搭
```
