# pet-wb Phase 1 共享层测试说明

> **版本**：v1.0  
> **测试范围**：共享层（登录/宠物档案/地址管理）+ 云函数 + Feature Flag  
> **测试环境**：微信开发者工具 + 云开发沙箱环境  

---

## 一、测试环境准备

### 1.1 前置条件

- [ ] `miniprogram/app.json` 中 `"appid"` 已替换为真实 AppID
- [ ] `cloudfunctions/` 下 16 个云函数已在微信开发者工具中右键「上传并部署」
- [ ] `miniprogram/` 根目录执行 `npm install` 并「工具 → 构建 npm」
- [ ] 云开发数据库已根据 `database/init.sql` 创建集合：
  - `common_user`, `common_pet`, `common_address`, `sys_feature_flag`

### 1.2 测试数据准备

在 `sys_feature_flag` 集合中手动插入以下初始化数据（若 `init.sql` 未执行）：

| flag_key | flag_value | module |
|----------|-----------|--------|
| module_wp_enabled | 1 | wp |
| module_gb_enabled | 1 | gb |
| module_mp_enabled | 0 | mp |
| module_mbti_enabled | 0 | mbti |
| mbti_social_mode | 0 | mp |
| wp_share_enabled | 1 | wp |
| gb_checkout_enabled | 1 | gb |
| mp_checkin_enabled | 0 | mp |
