# pet-wb 两模块收缩版 — 功能测试说明与测试计划

> **版本**：v0.1
> **范围**：穿搭 / 地图 两个 Tab；不覆盖团购、MBTI、旧版「我的」入口
> **执行方式**：用户手动功能测试 + 云函数控制台辅助验证
> **结果填写**：在每条用例的「结果」列填写 `通过 / 不通过 / 阻塞 / 暂不测`，并在「备注」记录现象或问题截图编号

---

## 1. 测试目标

本轮测试验证功能收缩后的第一版体验是否成立：

- 底部主入口只保留「穿搭」「地图」。
- 穿搭页完成宠物资料管理、照片展示、公开控制、别人家的随机展示和点赞。
- 地图页完成宠物友好地点浏览、详情信息、已有数据展示和遛狗聚合功能。
- 「我的」不作为主入口；相关宠物编辑能力并入穿搭。
