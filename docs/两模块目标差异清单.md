# PetMini 两模块目标差异清单

> 生成时间：2026-06-12
> 用途：给后续新工作区分支承接开发使用；当前工作区继续保留给真实测试。
> 范围：只对齐「穿搭」「地图」两个主模块，不覆盖团购、MBTI、支付、旧版个人中心完整能力。
> 依据：用户最新目标、`docs/测试计划-两模块收缩版.md`、当前工作区代码和微信开发者工具模拟器验证结果。

---

## 1. 状态标记

| 状态 | 含义 |
|------|------|
| 已具备 | 当前代码基本满足目标，只需要测试确认 |
| 部分具备 | 有页面或接口基础，但关键目标未闭合 |
| 未实现 | 当前代码没有对应功能或数据结构 |
| 需确认 | 实现前需要产品取舍或数据边界确认 |

---

## 2. 总体结论

当前项目不是“测试失败多”，而是“测试说明已经按新目标写好，代码还处于旧目标和新目标混合状态”。因此后续应按小批次开发：

1. 先改信息架构，让主入口变成两 Tab。
2. 再把宠物编辑入口收回穿搭页。
3. 再补宠物照片、公开状态、别人家的点赞闭环。
4. 地图模块保留当前已有数据和已有页面基础，只补目标差异。
5. 遛狗模块已有雏形，但隐私、聚合、15 分钟过期规则还需要重做。
