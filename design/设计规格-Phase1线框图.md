## 二、全局设计规范

### 2.1 视口

| 属性 | 值 |
|------|---|
| 设计基准宽度 | 375pt（iPhone 6/7/8/SE 标准） |
| 状态栏高度 | 20pt |
| 导航栏高度 | 44pt |
| Tab-bar 高度 | 50pt |
| 内容区（含导航） | ~603pt |

### 2.2 导航模式

```
底部 Tab-bar（4 Tab）
├── 穿搭 → 宠物选择 → 穿搭主页
├── 商城 → 商品列表
├── 地图 → 占位（Phase 1.5）
└── 我的 → 用户中心

子页面：顶部导航栏（返回箭头 + 标题 + 可选右侧操作按钮）
```

### 2.3 通用组件

| 组件 | 使用页面 | 描述 |
|------|---------|------|
| **空状态引导** | 宠物列表/穿搭方案/订单等 | 插画 + 引导文案 + CTA 按钮 |
| **加载骨架屏** | 所有列表页 | 灰色占位骨架 |
| **Toast** | 全局 | 成功/失败/提示，2s 自动消失 |
| **确认弹窗** | 删除操作 | "确定删除？" + 确认/取消 |
| **ActionSheet** | 规格选择/图片上传 | 底部弹出选项列表 |
| **导航栏** | 所有子页面 | 标题 + 返回箭头 |

### 2.4 按钮规范

| 类型 | 使用场景 | 样式 |
|------|---------|------|
| **主按钮** | 核心操作（登录/支付/保存） | 深色背景 + 白色文字，全宽 |
| **次按钮** | 次要操作（编辑/查看物流） | 白底 + 深色边框 |
| **文字按钮** | 轻量操作（删除/取消） | 纯文字 |
| **虚线按钮** | 新增/添加类操作（添加宠物/新建地址） | 虚线边框 + 加号 |

## 四、核心交互流程

### 4.1 穿搭→购买→解锁（核心闭环）

```
穿搭主页（看到心仪服饰）
    ↓
购买同款（跳转商品详情）
    ↓
查看规格 + 试穿预览（联动 #2）
    ↓
选择规格 + 确认地址
    ↓
微信支付（共享层）
    ↓
支付成功 → 自动解锁 2D 服饰（#5 → #2 addItem）
    ↓
返回穿搭主页 → 新服饰已出现
```

### 4.2 分享裂变

```
穿搭主页 → 分享
    ↓
Canvas 生成分享卡片（2D形象 + 穿搭名 + 小程序码）
    ↓
保存图片 / 发送好友
    ↓
好友扫码 → 登录 → 创建宠物 → 触发穿搭引导
```

### 4.3 新人引导（3 步）

```
Step 1: 创建宠物档案（共享层）
Step 2: 选择 2D 基础形象（8 种预设）
Step 3: 试穿免费服饰 → 分享穿搭
```

## 五、模块联动设计要点

| 联动 | 方向 | 说明 |
|------|------|------|
| 穿搭 ↔ 团购 | 双向 | 穿搭页可"购买同款"跳转商品详情；商品详情显示宠物试穿预览 |
| 团购 → 穿搭 | 单向 | 支付成功后自动调用 #2 addItem 添加服饰 |
| 团购 ↔ 共享层 | 双向 | 下单调用共享层支付接口；地址管理使用共享层地址表 |
| 穿搭 → 共享层 | 单向 | 创建 2D 形象时获取宠物基础信息 |

## 六、状态与异常设计

### 6.1 空状态规范

| 页面 | 空状态文案 | CTA |
|------|-----------|-----|
| 宠物列表 | "还没有宠物，快来创建一只吧" | 添加宠物 |
| 穿搭方案 | "还没有穿搭方案，去试试换装吧" | 去换装 |
| 收货地址 | "还没有收货地址" | 新增地址 |
| 订单(全部) | "还没有订单" | 去商城逛逛 |
| 商品列表 | "暂时没有商品" | - |

### 6.2 加载态

- 列表页：骨架屏（灰色占位块模拟 card 结构）
- Canvas 渲染：loading 动画 + 占位图
- 支付：按钮 loading + "支付处理中..."

### 6.3 错误态

- 网络错误：Toast "网络异常，请重试" + 重试按钮
- 支付失败：Toast 提示具体原因
- 资源加载失败（2D 图片）：显示默认占位图
